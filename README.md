# SmartTrace-Dashboards

SmartTrace Dashboard application built with React and Vite.

## Features
- **Hospital Dashboard**: Live monitoring, alert logs, and system metrics for smart trace devices.
- **Compliance Dashboard**: Interactive compliance tracking and analytics.

## Tech Stack
- React
- Vite
- Lucide React (Icons)
- Recharts (Data visualization)

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```
